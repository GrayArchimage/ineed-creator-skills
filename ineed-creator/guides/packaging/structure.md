# ZIP 结构与路径

## 必须满足

- 上传静态网页 ZIP，推荐 ZIP 根目录直接包含 `index.html`。
- 页面引用本包资源时使用相对路径，保留文件名大小写。部署目录不是网站域名根目录。
- 单个规范化路径不超过 240 个字符；不允许绝对路径、跳出站点目录或重复路径。
- 保持 Godot 同批导出的 HTML / JS / WASM / PCK 及必要 worklet 文件相互匹配，不只重命名其中一个文件。

```text
my-game.zip
├── index.html
├── index.js
├── index.wasm
├── index.pck
└── assets/
    └── cover.webp
```

平台能识别所有有效文件均位于一个公共父目录的包装层，并剥离该层。多作品、多入口或夹杂根外文件不应依赖此兼容处理；交付时仍推荐规范根目录。

## 不要加入

`.git/`、`node_modules/`、`.env`、私钥、编辑器缓存、源工程及未使用素材。构建工具配置不是运行资源，不能把整个开发目录直接压成 ZIP。`.DS_Store`、`__MACOSX` 等系统产物会被忽略，但仍建议打包前移除。

平台只提供静态托管，不启动 Node/Python/PHP 或数据库。Godot 包根的 `.htaccess`、`_headers`、`serve_release.py`、`启动网页游戏.bat` 会被识别为本地部署辅助文件，不执行、不对外提供；这不等于任意服务器脚本都受支持。

## Web 工程

先运行项目已有的生产构建，上传生成的静态输出目录。排除 `localhost`、`127.0.0.1`、`/@vite/client`、webpack 开发服务器残留。SPA 优先使用 hash 路由或输出真实 HTML 页面；不要假定托管会为任意路径自动回退到首页。

## 原始档案

源 ZIP 作为审计输入保留。审核和兼容处理不授权执行档案中的脚本，也不授权改写内部玩法。压缩前后均需核对[容量限制](limits.md)和[支持类型](formats.md)。
