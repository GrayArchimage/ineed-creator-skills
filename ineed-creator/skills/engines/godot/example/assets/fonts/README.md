# iNeed Creator CJK

Derived from Noto Serif CJK SC, distributed under SIL OFL 1.1 (see OFL.txt and embedded copyright metadata). The subset family is renamed iNeed Creator CJK. WOFF2 reduces download size; no network font loader is used.

Coverage: U+0000–024F, U+2000–206F, U+3000–30FF, U+3400–9FFF, U+FF00–FFEF, where present in the original font. This covers basic CJK and Extension A; it does not promise Extension B+, emoji, or all languages.

Keep the font license with copied assets. Check the final game package budget before including it; existing game fonts can be used when their glyph coverage is adequate.

Godot FontFile supports WOFF2: https://docs.godotengine.org/en/4.3/classes/class_fontfile.html
