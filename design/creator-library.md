# 创作者文档库设计增量 · 2026-09-28

状态：用户于2026-09-28确认深色方向，随后批准“简洁舒适一些，没问题就可以了”。落实为弱边框、少卡片、正文优先的静态文档库。

用途：长期维护的中文技术文档库，面向创作者及其 AI。桌面阅读约 1m，手机约 10cm；克制、清晰，正文优先。

## Design Decisions

- 复用 iNeed 已批准系统：主页面底 #262B39，导航面 #303246，主文字 #F9F9F9，辅助 #92A1B3，重点珊瑚红 #F36463。浅色浮层规范不套用于本次文档页面；黑底代码区域使用页面深色系。
- 正文使用 PingFang SC / Microsoft YaHei / Noto Sans CJK SC；代码等宽字体；正文 16px，行高 1.8。
- 4px 间距基准；导航/输入圆角12px，内容入口18px；发丝边框、无硬投影；140ms轻量状态变化，支持减少动画。
- 桌面：顶部品牌/版本/搜索/下载，左侧分类目录，中间正文，右侧当前章节；首页有快速开始、分类入口和发布信息。
- 手机：820px以下折叠左侧目录，正文单列；章节目录置于正文上方；触控目标44px以上。相同内容与顺序。
- 新增独立文档库入口；上传对话保留现有ZIP下载，增加“查看文档”入口。账号、作品页面、SDK协议及旧下载URL不改语义。
- iNeed Logo只复用平台仓库 public/ineed-icon.svg；ImageGen不得重绘正式标志；概念图仅探索文档区增量。

## 信息架构

开始使用 / 引擎接入（Web、Godot） / 平台能力（登录、支付、排行榜、激励广告、存档） / 打包与导出（结构、类型、大小、压缩、Godot导出、资源访问与验收、常见问题） / SDK协议与兼容 / 版本与下载。

## 可抓取及分发

正文预生成HTML且无需执行JavaScript，无登录要求；每页独立URL/标题/canonical；真实锚点目录与普通链接；提供原始Markdown、llms.txt、站点地图。搜索仅增强浏览，关闭JS仍可遍历阅读。Markdown是单一内容源；同时生成完整技能ZIP（含插件、脚本、示例）及仅Markdown文档ZIP，后者明确不含可运行SDK。保留历史Release契约及旧下载地址。
